Privacy Policy

1. General Information

Protecting your privacy is important to us. This Privacy Policy explains how data is processed when you use the online game and website FootballManager.IO.

The website can be used without providing personal data beyond what is technically necessary to operate the service.

2. Account Registration

To use the game, users register with:

  • a username
  • a password

No email address is required for registration. Passwords are stored only in encrypted and hashed form and cannot be read by the operator.

3. Cookies & Tracking

This website does not use:

  • Cookies
  • Tracking or analytics tools
  • Third-party services or embedded external content

User behavior is not tracked across sessions or websites.

4. Server Log Files

For technical and security reasons, the server may automatically collect limited data:

  • IP address (temporarily)
  • Date and time of access
  • Browser and operating system (basic technical information)

This data is used solely to ensure the secure and stable operation of the website and is not combined with other data sources.

5. Data Sharing

No personal data is shared with third parties.

6. Data Storage & Deletion

User data (username and game-related data) is stored only for as long as the user account exists. Users may request deletion of their account and all associated data at any time.

7. User Rights

Users have the right to:

  • object to data processing where legally applicable
